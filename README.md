# Unit Converter

A simple Android app for converting length measurements, built with Kotlin and Jetpack Compose.

## Features

- Convert between meters, centimeters, millimeters, and feet.
- Select input and output units using dropdown menus.
- See the result update automatically when changing the value or units.
- Results rounded to two decimal places.

## Technologies

- Kotlin
- Jetpack Compose
- Material 3
- Android Studio
- Gradle

## How to Run

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Wait for Gradle Sync to finish.
4. Run the app on an Android emulator or a physical Android device.

## How to Use

1. Enter a numeric value.
2. Select the original unit from the left dropdown.
3. Select the target unit from the right dropdown.
4. Read the conversion result below the buttons.

Use a decimal point when entering decimal values, for example `1.5`.

## About This Project

This project was created while following an Android development course to practice Kotlin and Jetpack Compose.

It focuses on state management, user input, dropdown menus, and unit conversion logic.
